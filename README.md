# 声屿 · Sound Island

极简音频网页：一个入口按钮，六个声音按钮。点击停止上一段并从头播放新声音一次；重复点击同样从头播放。支持手机、键盘操作和减少动态效果设置。视觉取青绿色与几何元素方向，非 Mikutap 复刻。

## 本地运行

无需安装依赖。需要 Python 3 和 Node.js（测试）。

```sh
cd /workspace/Savgreetings
npm start
```

默认端口 8000。也可用任何静态服务器托管此目录；不要直接使用 file:// 打开，浏览器模块需要 HTTP。

## 接入音频

将六个文件放在 `audio/`，编辑 `audio/tracks.js` 对应项，例如 `{ name: '声音一', src: './audio/01.mp3' }`。支持浏览器兼容的 MP3、WAV 等文件。当前没有音频文件，点击显示「音频待添加」，不会播放占位声音。

## 验证

```sh
npm test
```

测试音频控制器的中断、重播、快速切换、过期事件、播放失败和停止行为。尚需提供真实音频后进行浏览器听感与格式兼容性验证。
