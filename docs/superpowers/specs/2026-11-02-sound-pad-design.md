# Sound pad design
Approved: a turquoise fullscreen landing screen with one Start button; a responsive six-pad player (3 columns desktop, 2 mobile); geometric click feedback. Each click stops and resets previous audio, including repeat clicks. Play once, no loop. Missing files show 音频待添加. Audio files will be supplied later.
Approaches: native HTML/CSS/JS chosen for a small static site without dependencies; a framework adds unnecessary setup. No backend needed.
